# 🎨 Palette Generator

A modern, interactive color palette generator built with HTML, CSS, and JavaScript. Choose a base color, generate harmonious color combinations, customize your palette, and export colors for your next design or development project.

## ✨ Features

- 🎨 **Custom Base Colors** — Choose a color using the color picker or enter its HEX code.
- 🌈 **Six Palette Modes**
  - Complementary
  - Analogous
  - Triadic
  - Tetradic
  - Monochromatic
  - Shades (dark to light)
- 🔢 **Adjustable Swatch Count** — Generate between 3 and 10 colors.
- 🎲 **Random Color Generator** — Discover new color combinations instantly.
- 📋 **Copy Colors** — Copy individual HEX codes, a complete HEX list, or CSS variables.
- 📥 **Export Palettes** — Download your palette as `.css` or `.txt`.
- 🔄 **Reset Controls** — Restore the default color and settings.
- 📱 **Responsive Design** — Adapted for desktop and mobile screens.
- 💜 **Modern Interface** — Dark theme, purple gradients, and a polished user experience.

## 🛠️ Technologies

- **HTML5** — Application structure.
- **CSS3** — Responsive layout, gradients, and styling.
- **JavaScript (ES6+)** — Color calculations, palette generation, clipboard operations, and downloads.
- **Google Fonts** — Poppins and Inter typography.

## 🚀 Getting Started

### Prerequisites

A modern web browser is all you need.

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/BenkabaMarwa/palette-generator.git
   ```

2. Navigate to the project folder:

   ```bash
   cd palette-generator
   ```

3. Open `index.html` in your browser.

No package installation or backend server is required.

## 📖 How to Use

1. **Choose a base color** using the color picker or enter a HEX value.
2. **Select a harmony type** from the available palette modes.
3. **Adjust the swatch count** to generate between 3 and 10 colors.
4. **Generate a random color** if you want to explore new combinations.
5. **Click a color swatch** to copy its HEX code.
6. **Export your palette** by copying CSS variables or a HEX list, or downloading a `.css` or `.txt` file.
7. Use **Reset** to return to the default settings.

## 💡 Example CSS Output

The generated palette can be exported as CSS custom properties:

```css
:root {
  --color-1: #8057FF;
  --color-2: #A78BFA;
  --color-3: #C4B5FD;
  --color-4: #DDD6FE;
  --color-5: #EDE9FE;
  --color-6: #F5F3FF;
}
```

*Example values only. Your exported colors depend on the selected base color and harmony mode.*
